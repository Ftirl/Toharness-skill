## 3. Feedback Loop

```text
Telemetry
↓
Routing Recommendation
↓
Codex / 用户审核
↓
决定是否修改 Router Policy
```

Telemetry MAY 作为 soft signal，但 MUST NOT：

```text
自动修改本 Skill
自动降低 Risk
自动跳过 Review
覆盖当前用户要求
覆盖当前 Capability State
```

小样本时只报告趋势，不自动改变路由。

## 4. 优化目标

MUST NOT 单纯优化最低 Token，而优化：

```text
Quality × Reliability / Cost
```

推荐成本链路：

```text
Codex
→ 短 Contract
→ Harness 大量执行
→ Result Compression
→ Codex Evidence-based Review
```
